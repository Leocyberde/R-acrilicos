# Gestão Pró

Sistema de gestão empresarial completo para prestadores de serviços.

## Funcionalidades
- Gestão de Clientes
- Orçamentos e Pedidos
- Ordens de Serviço
- Recibos e Financeiro
- Integração com WhatsApp para notificações e envio de PDFs

## Como executar localmente
1. Instale as dependências: `npm install`
2. Configure as variáveis de ambiente no ficheiro `.env`
3. Inicie o servidor de desenvolvimento: `npm run dev`
